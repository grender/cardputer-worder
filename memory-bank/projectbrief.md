# Project Brief: card-worder

**Last Updated:** 2026-03-17

---

## Overview

**card-worder** (crate: `cardworder`) is an embedded Rust application for M5Stack Cardputer (ESP32). It uses spaced repetition (FSRS via `rs-fsrs`) and provides a flashcard/word-learning experience on the device (embedded-graphics display, SD card storage).

## Tech Stack

- **Target:** ESP32 (esp-idf)
- **Language:** Rust 2021
- **Key deps:** esp-idf-svc, esp-idf-hal, embedded-graphics, embedded-sdmmc, rs-fsrs, heapless, serde/serde_json
